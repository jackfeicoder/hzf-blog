# 访客看板权限

- 仅指定站点管理员 jackfei 可查看访客看板。服务端复用 `require_superadmin`，普通用户及仅有旧 `is_admin` 标记的用户均返回 403；未登录或失效令牌返回 401。
- 桌面导航及手机侧栏根据 `/api/auth/me` 返回的严格布尔值 `can_manage` 显示入口，页面直达链接在登录状态核验完成后拦截，拒绝者返回首页。登录核验期间不加载访客页面或请求日志接口。
- 管理员的访客接口返回 `Cache-Control: private, no-store`、`Vary: Authorization`，避免敏感日志进入公共缓存。
- 文章访问继续收集日志，现有日志与滚动清理策略保留。本次不迁移、删除数据库记录。
- 权限回归测试涵盖匿名、失效令牌、普通账号、旧管理员账号、指定管理员，以及拒绝请求不会记录看板访问、正常文章访问仍被记录。

## 每日去重（2026-10-15）

- 按北京时间自然日（00:00 至次日 00:00）记录，同一 IP 无论访问多少篇文章、是否登录，当天只新增一条；次日可再次记录。路径、身份和时间保留首次记录的信息。
- 新增 `visit_days` 唯一键表（IP + 日期），SQLite 通过原子冲突忽略插入处理并发，其他数据库使用事务保存点，不回滚文章阅读量等外层变更。启动时自动创建该表，不重写旧表。
- 上线当天已存在的日志也参与去重；旧日志不批量合并或删除，原七天滚动清理继续保留。历史累计记录数可能包含此前一天多条的记录。
- 今日统计采用同一北京时间边界；访客看板仍仅管理员可见。
