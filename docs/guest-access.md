# 访客访问范围

- 未登录用户可打开首页、注册、登录，以及作为重定向目标的首次介绍页 `/welcome`。
- 其他站内页面统一等待登录状态校验；未登录跳转介绍页。失效令牌不会造成介绍页与首页间循环跳转。
- 导航隐藏未登录不可用的功能；音乐播放引擎仅在已登录时挂载，退出时销毁播放器。
- 后端应用统一使用默认拒绝的业务接口白名单策略。首页仅开放文章摘要列表、分类、热门侧栏和外观，介绍页使用专用作者简介接口。
- 文章全文、评论、个人主页、视频链接、音乐推荐/搜索/解析/歌词、AI等业务接口要求有效登录；管理员权限继续独立校验。
- 头像、背景、封面等图片资源仍公开，首页需要展示它们；音频文件继续使用原有签名播放凭证，不要求音频标签添加 Authorization 请求头。已有签名链接不因本次修改撤销，内部缓存目录仍由 Nginx internal 保护。
- 注册用户名沿用现有区分大小写规则，首尾空格会去除；昵称允许重复。用户名重复统一返回409，不签发令牌、不修改旧账号、不消耗邀请码。
- 并发提交相同用户名由数据库唯一约束兜底。已登录用户在注册页看到当前账号提示，需先退出才显示注册表单。
