# 音乐播放器

`/music` 是按需加载的页面。第一次访问时挂载持久 Audio 控制器，站内路由切换保持播放；刷新页面后需重新点播放。登录账户的收藏、歌单、最近 100 首保存在 SQLite；游客数据仅本次会话有效。退出登录立即停播并清空私人状态。音量是非敏感本地偏好。

## 网络与性能

- 五个平台、每页 20 首：小云使用 GD Studio / 原生元数据接口，其他平台使用各自的元数据适配器。搜索主动提交，可取消；旧响应不覆盖新搜索。
- 第一页遇到 502/503/504、网络错误或超时，自动尝试两个备用平台，采用先返回有效非空结果的平台，取消另一个请求，并同步平台选中状态。最多三个请求，每个请求预算 8 秒；失败平台在当前页面会话暂时跳过 60 秒。401/403/429/参数错误不触发换源，正常空结果保留；第二页及之后保持原平台，重新搜索可再次自动选择。
- 播放遇到非 JSON 网关错误会自动重试一次；后端已尝试启用音源后返回的业务错误不重复请求。搜索换平台不等于启用新播放音源；关闭的源始终保持关闭。
- 服务端搜索缓存 5 分钟、歌词 1 小时、已解析 URL 2 分钟（可能提前失效，可换源）。300 项上限；其中封面最多 24 项、单图 512 KB。
- 个人数据 `private,no-store`。控制器的进度订阅与歌曲列表分离。
- 音源解析最多试 4 个、单个容器 12 秒、一次解析总计 28 秒；播放错误或卡缓冲可排除当前源尝试下一个。最多 4 轮播放器换源。用户主动暂停及浏览器自动播放限制不触发换源。
- 标准 128k 默认，更适合当前小带宽服务器；可手动选择高音质。支持 Range，拖动进度无需重下整首。音频流不保存磁盘；服务器同源流转发避免跨域、混合内容与泄漏第三方密钥。
- 播放凭据随机、服务器内存保存、有效 30 分钟、500 项上限。重启服务或地址过期后重新播放即可。

## 音源隔离

jackfei 可导入 `.js/.cjs`（600 KB，最多 30 个）、测试、调整优先级、启停、删除。默认来源是 pdone/lx-music-source 固定提交的十份本地归档。仅实际样本音频验证成功者启用；兼容测试不代表所有歌曲可播放。支持常见 LX API；桌面专属能力和需要外部密钥的源可能需调整。

原脚本放 SQLite，不发送到前端。一次一个临时 Docker：无网络、非 root、只读、cap-drop ALL、no-new-privileges、24 PID、128 MB、0.5 CPU、墙钟超时清理。容器镜像离线从服务器现有 Node + 运行库构建；不暴露 Docker socket、博客目录或 `.env`。Node vm 仅兼容 LX，不作为隔离边界。

网络由宿主 Python 桥处理，限制 GET/POST/HEAD、80/443、头/体/响应大小。DNS 检查所有结果，拒绝私网、元数据、环回、保留及组播地址，连接固定已验证 IP，TLS 仍校验域名；逐次验证跳转。不会继承系统代理、Cookie 或博客 Authorization。不执行自动更新返回的脚本。

部署：`tools/prepare_music.py` 在临时目录检验归档 SHA256、构建镜像及测试。`tools/deploy_music.py` 复用现有备份/回滚流程，仅发布清单内文件；启动时新增表，备份 SQLite、源码、HTML，保留旧哈希资源。增加 `90-music.conf` 环境开关，失败恢复。不要手动输出或提交导入脚本中的密钥。

## 公开推荐与播放设置

进入 `/music` 默认展示「推荐歌曲 · 管理员的歌单」。`GET /api/music/recommended` 只读管理员的 favorites，游客可访问；不返回登录用户名、历史、自建歌单、私人列表编号或其他用户数据，响应为 `no-store`。

jackfei 编辑「我喜欢」后更新推荐内容；其他访问者进入推荐页、点击「刷新推荐」或重新激活浏览器页面时重新读取。各用户的收藏和添加操作仅作用于自己的歌单。

底栏显示「播放设置」「音量」和「播放队列」，设置弹层包含播放模式和音质；音量显示百分比，队列显示歌曲数量。手机全屏播放器提供相同控件。模式与音量切换直接作用于本地播放器，不重新解析音源。

## 验证

后端 `python -m unittest discover -s tests -p 'test_*.py' -v`（cwd backend）。前端 `npm test && npm run build`。`backend/tests/preview_study.py` 提供临时 SQLite + 本地合成测试音频用于 UI 验收，绝不使用生产账户。

本地预览进程设置 `MUSIC_PREVIEW_FAIL_SEARCH=tx`，可模拟小Q搜索失败并验证自动切换；这个开关仅存在于测试入口，不影响生产。前端定向发布脚本 `tools/deploy_music_fallback.py` 先校验线上源码摘要，备份 SQLite、源码和前端资源，通过回归测试后原子切换入口，无需重启后端。上线失败恢复原入口，保留新增哈希资源用于兼容旧标签页。
