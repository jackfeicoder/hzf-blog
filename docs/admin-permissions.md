# 文章删除与集中管理

- 普通用户仅能修改、删除自己的文章；旧的 `is_admin` 标记不再赋予跨用户文章权限。
- `jackfei` 为超级管理员，可以读取草稿、编辑或删除所有作者的文章。
- `DELETE /api/posts/{id}` 必须有 JSON 请求体 `{"password":"操作者自己的登录密码"}`。
- 后端先验证作者/超级管理员身份，再校验当前操作者的密码；前端仅在临时弹窗中持有密码。
- 删除密码确认最多每账户每五分钟五次失败尝试；成功确认后清除计数。当前为单进程内存限流，多进程部署时应换成共享限流存储。
- 删除文章同步清理评论、标签关联、点赞、收藏，并把相关通知的文章 ID 置空；不删除公共标签和学习历史快照。

## 集中后台 `/admin`

仅 `jackfei` 可进入。所有 `/api/admin/*` 接口独立验证身份，响应设为 `private, no-store`。

- 文章：分页搜索、读取草稿、创建、编辑、本人密码确认后删除。
- 用户：分页搜索、创建、修改昵称/简介/头像、管理员本人密码确认后删除。用户名固定，不暴露密码哈希，不支持页面直接修改密码；保留 `jackfei` 账户。
- 删除用户会清理其文章、评论及回复、互动、通知、关注关系、打卡数据，并修复存量文章计数、解除访客记录关联。
- 新登录令牌绑定账户 ID 和创建时间；兼容现有固定 30 天到期的令牌，同时拒绝早于账户创建的令牌，防止删除后重建同名账户继承旧登录状态。
- 分类：新增、重命名、删除。删除分类保留文章，文章改为未分类。
- 评论：全站分页搜索、编辑、删除（连同回复）；新增在对应文章内进行。
- 打卡：选择用户后显式读取/生成今日任务、修改完成/待加强/备注、查看月度历史和轮次、开启已完成轮次的下一轮。历史快照只读；重置全部个人学习数据需要管理员本人密码确认，公共题库保留。
- 视频链接和公共题库通过后台快捷入口进入现有管理页面。

后台页面独立懒加载，列表限制每页 20 条，打卡用户搜索每次最多 50 条；不在首页请求后台数据。

## 验证与发布

`backend/tests/test_permissions.py` 使用临时 SQLite 数据库且启用外键，验证权限、密码、关联清理和超级管理员例外。

`tools/deploy_permissions.py` 复用已有发布流程：在线 SQLite 备份、源文件/前端备份、服务端隔离测试、健康检查、哈希资源先发布、HTML 最后切换；应用失败时回滚源文件与入口。
