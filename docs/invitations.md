# 邀请注册与访客列表

- 管理后台 → 邀请码：仅站点超级管理员可以生成、查看、复制或作废邀请码。
- 邀请码由密码学安全随机数生成，使用6位大写字母和数字，排除易混淆字符；输入不区分大小写。
- 每码仅可成功注册一次，不设自动过期。未使用的邀请码可作废，已使用的保留注册用户名和时间供管理员核对。
- 管理后台 → 邀请码顶部的“开启邀请注册”开关统一管理全站注册规则，仅超级管理员可修改，切换需确认，默认开启。
- 开启时注册接口强制校验邀请码；关闭时注册页隐藏邀请码输入框，后端允许无邀请码注册，且不消耗已有邀请码；重新开启后未使用的邀请码仍有效。
- 注册规则保存在服务器 `registration_settings` 数据表中，不依赖浏览器或进程内存。读取失败时注册页面禁用提交并提供重试。
- 注册接口按IP限制尝试次数；账号创建和邀请码使用状态在同一事务提交。
- 已有账号和登录凭证保持不变；管理员后台直接创建用户保留原有权限。
- 邀请码保存在服务器新增的 `registration_invites` 数据表中，只有管理员接口可以读取，响应禁止缓存。
- 访客列表最多返回10个不同IP，登录与游客统一按IP去重。同账号使用不同IP分别显示，同IP切换用户以最近访问者为准。
- 页面路由切换后台上报一次，同IP每天仅新增一条，之后更新该条的最近用户、页面和时间。七天保留不变，旧记录不批量删除；跨天的同IP记录在列表中也只展示最近一条。
- 邀请注册只限制创建账号，不会把原本公开的文章、接口或媒体自动变成私有内容。
