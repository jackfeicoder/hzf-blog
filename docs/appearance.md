# 全站外观与特效

管理员点击顶部调色盘或侧边菜单的「全站外观与特效」，可以统一设置浅色/深色、主题配色、页面背景、鼠标样式、点击特效和过渡动画。

毛玻璃透明度为 0%～80%：0% 不透明，数值越大越通透。只调整背景透明度，不降低文字或按钮的透明度；导航和抽屉保留轻量模糊，不为每张卡片增加模糊层。

调整即时预览，点击「应用到全站」才写入服务器。「撤销预览」恢复已发布样式，「恢复默认」仍需点击应用才发布。背景上传限制 2MB，使用现有图片存储和 30 天图片缓存；应用后的背景对所有人公开。

## 权限与兼容

- `GET /api/appearance` 公开返回全站配置，不含管理员身份或账户信息，响应 `Cache-Control: no-store`。
- `PUT /api/appearance` 仅指定管理员可用；除设置字段外必须包含 `scope: "site"`，阻止旧客户端的个人设置自动保存覆盖全站样式。
- `site_appearance` 为新增单例表（id=1），由现有启动逻辑创建。旧 `user_appearance` 数据完整保留，不再作为各用户的独立样式使用。
- 首次发布前使用指定管理员原有设置作为全站默认；原「跟随系统」转换为浅色，确保明暗模式统一。
- 浏览器仅缓存已发布的全站快照，采用新缓存键 `blog_site_appearance_v2`，忽略旧个人缓存和未同步标记。管理员预览不写入共享缓存。
- 前台页面每 30 秒后台检查一次；重新聚焦、联网或打开页面也检查。隐藏页面停止定时读取。网络异常保留上次全站样式，不阻塞内容或图片加载。
- 设备的「减少动态效果」仍优先暂停动画，这是无障碍保护，不更改全站配置。

## 验证

后端测试涵盖管理员权限、访客与普通账号读到相同设置、透明度边界、旧客户端保护和旧数据保留；前端测试涵盖共享缓存、旧缓存隔离、透明度转换和公开读取。`backend/tests/preview_appearance.py` 提供回环地址、临时数据库的 UI 夹具，供本地桌面/390px 手机布局验收使用，不部署到生产服务。
