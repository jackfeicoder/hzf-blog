# 2026-09-30 性能优化

## 已落实

- 首页只加载列表与导航；文章、写作、AI、排行、个人页、访客、登录和打卡按路由拆包。
- 普通时间/数字工具独立为 `format.js`，首页不再间接加载 Markdown / DOMPurify / 代码高亮。
- 高亮库只注册 Java、JS、TS、Python、SQL、Bash、JSON、HTML/XML、CSS、C/C++、Go、Markdown。未声明或尚未支持的语言保留转义后的纯文本，不再遍历全量语言自动猜测。文章内容和代码复制保留。
- 首页文章列表、分类、热门榜、作者榜使用内存缓存：30 秒内复用，重复请求合并；过期后先显示最多 5 分钟内的已有内容，后台刷新。超过 5 分钟的旧值不再展示，最多保存 80 个查询键。
- 搜索、分页、分类、标签和排序分别缓存。用户登录/退出/切换令牌清空缓存；发布、修改、删除、点赞、收藏、评论和头像修改后使相关公共缓存失效。旧请求在失效后不再填回缓存。
- 支持草稿的作者文章列表、通知、个人打卡等接口不缓存，不改变 Cloudflare 私有数据缓存规则。
- GET 请求最多等待 15 秒并显示重试提示；写操作不增加自动超时/重试，避免重复提交。网络失败不再清除有效登录令牌，仅 401/403 清除。
- 打卡任务先显示，轮次随后加载；文章正文和评论并行，评论失败不遮住正文。
- 编辑器关闭预览时不在每次输入时解析和高亮全文。
- 后端列表、热门文章、收藏列表不读取全文；分页计数直接计数而非带正文的 ORM 子查询。

## 验证与限制

前端使用 Node 内置测试（`npm test`）；后端 `python -m unittest discover -s tests -v` 包含列表 SQL、草稿隔离和打卡回归。构建 `npm run build`。

本次优化不修改代理、DNS、端口、Cloudflare 路由、SQLite 日志模式或服务器规格。之前测量存在公网链路超时，减小页面与请求数量并不等同于消除网络波动。备份、服务器端测试、健康检查通过后才切换首页构建产物；旧哈希资源保留以支持回滚和已有页面。
