# 休闲模块

- 导航“看视频”对应 `/videos`，所有访客可查看、搜索公开链接，新标签页打开外站。
- `jackfei` 登录后可以新增、编辑、删除链接，并调整名称、简介和排序（数字小的靠前）。后端独立核验账号，隐藏按钮不是唯一权限控制。
- 数据保存在现有数据库的新增表 `video_links`，不添加默认电影链接。
- “听音乐”对应 `/music`，已实现搜索、歌单、歌词、队列和公开推荐；详见 [音乐播放器](music.md)。
- 两个页面按路由拆包，首页不加载视频页脚本。视频页只有一个列表读取请求；复用 30 秒内内存缓存，最多 5 分钟内的旧值先显示再刷新；写入后立即更新当前列表并使缓存失效。
- 外站只作为链接展示，不加载播放器、预览或远程图标，不通过服务器抓取外站内容。
- 权限与 URL 校验、CRUD 持久化、排序和缓存失效使用隔离数据库/请求测试；本地预览账号仅在 `tests/preview_study.py` 临时数据库中存在。
